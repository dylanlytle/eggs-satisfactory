# Contributing

This is a friendship-first factory plan. Changes should make ownership clearer,
coordination easier, or the campaign more fun.

## Editing rules

- Treat `content/handbook.md` as the source of truth.
- Give every production line one accountable owner.
- Discuss changes to the world grid, rail direction, power policy, or factory
  contracts before merging them.
- Do not remove another player's role or factory assignment without their input.
- Prefer clear rates and interfaces over prescriptive internal factory layouts.
- Keep jokes, role names, and ceremonial nonsense unless the group agrees that
  they have become a genuine throughput bottleneck.

## Pull request checklist

- [ ] The source Markdown remains readable on GitHub.
- [ ] The PDF generator completes without errors.
- [ ] Tables fit on the page.
- [ ] Space Elevator quantities match the current game version.
- [ ] Shared-standard changes have been reviewed by another player.
- [ ] The pull request explains which players or factories are affected.
